Query Document:
Basic syntax of find() method is as follows
        >db.COLLECTION_NAME.find()
	>db.post.find({key1:value1, key2:value2})

The pretty() Method
	To display the results in a formatted way, you can use pretty() method.

Example (Display all):
	>db.post.find().pretty()
	>db.post.find({"by":"tutorials point"}).pretty()

Update Document:
Basic syntax of updateOne() or updateMany() 
method is as follows
	>db.COLLECTION_NAME.update({SELECTIOIN_CRITERIA}, {UPDATED_DATA})

db.collection.updateMany(
   { filter },
   { update },
   { options }
)

OR


The replaceOne() 
method replaces the existing document with the new document passed in replaceOne() method
Syntax




Example1:
	>db.post.updateone({'title':'MongoDB Overview'},{$set:{'by':'ITI'}})

Example2:
	
	>db.mycol.updateMany({'title':'MongoDB Overview'},
   {$set:{'title':'New MongoDB Tutorial'}})

Example3 (replaceOne):
	>db.mycol.replaceOne({
      {'title':'MongoDB Overview'}
    },
   {
      "_id" : ObjectId(5983548781331adf45ec7), "title":"Tutorials Point Overview",
         "by":"Tutorials Point"
   }
)


////=================DELETE===================================
Delete Document:
Basic syntax of deleteOne or deleteMany method is as follows
	>db.COLLECTION_NAME.deleteOne(DELLETION_CRITTERIA)

To remove all (like truncate in SQL)
	>db.NAME.deleteMany()

Example1(Remove only one):
	>db.mycol.deleteOne{'title':'New MongoDB Tutorial'})

Example2 (Remove all fields but remain collection strc):
	>db.mycol.deleteMany({})


Delete a specific collection
        >db.myCollection.drop()

To delete an entire database 
         >db.dropDatabase()

///=========================OPERATORS========================

1️⃣ Comparison Operators 
Equality:
	db.mycol.find({ grade: { $eq: 90 } })
	db.mycol.find({ grade: 90 })

 
Not Equals 	
	db.mycol.find({"likes":{$ne:50}})

Less Than:
	db.mycol.find({"likes":{$lt:50}})

Less Than Equals:
	db.mycol.find({"likes":{$lte:50}})

Greater Than
	db.mycol.find({"likes":{$gt:50}})

Greater Than Equals 	
	db.mycol.find({"likes":{$gte:50}})

$in
db.students.find({ grade: { $in: [70, 80, 90] } })

$nin
db.students.find({ grade: { $nin: [0, 50] } })

2️⃣ Logical Operators 

And Condition:
🔹 $and
>db.mycol.find(
   {
      $and: [
         {key1: value1}, {key2:value2}
      ]
   }
)

db.students.find({
  $and: [
    { grade: { $gt: 70 } },
    { age: { $lt: 25 } }
  ]
})


🔹 $or
OR Condition:
>db.mycol.find(
   {
      $or: [
         {key1: value1}, {key2:value2}
      ]
   }
)


Example:
	>db.post.find(
	{$or:[
		{"likes":100},
		{"title":"NoSQL Database"}
	]})
🔹 $not // 🔹 $nor

3️⃣ Update Operators ( )
🔹 $set
db.students.updateOne(
  { name: "Esraa" },
  { $set: { grade: 100 } }
)

🔹 $inc>>increase // +//-
db.lab_orders.updateOne(
  { _id: 1 },
  { $inc: { totalTests: 2 } }
)

🔹 $unset >>remove age field
 { $unset: { age: "" } }

 🔹 $push //🔹 $pull
db.CollentionName.updateOne({name:"ahmed"}, { $push: { skills: "MongoDB" } })

// add in index of selected array 
db.post.updateMany({},{$push:{"tags.3":"esraa"}})

// more elements
db.collectionName.updateOne(
  { name: "ahmed" },
  { 
    $push: { 
      skills: { $each: ["MongoDB", "Node.js", "Express"] } 
    } 
  }
)

4️⃣ Element Operators
🔹 $exists //🔹 $type
db.students.find({ age: { $exists: true } })

--------
db.students.find({
  age: { $type: "string" }
})

5️⃣ Evaluation Operators
🔹 $regex 
db.students.find({ name: { $regex: "^E /e" } })
